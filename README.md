## 🔄 v1 → v2 변경사항

**제거됨**
- 💰 현상금 시스템 (`/bounty`) — 전체 제거
- 💀 사망 위치 (`/deathpoint`) — 제거 (유언 `/유언`은 그대로 유지)
- 🔥 킬 스트릭 보상 (다이아·XP 지급, KDA 배율, 연속킬 전체 방송) — 제거. 연속킬 카운팅 자체(`/kills`, `/top streak`)와 그걸 이용하는 전투락은 유지
- 🧮 수학 퀴즈 (`/mathquiz`) — 전체 제거
- 🏆 시즌 시스템 (`/season`, SMP 시작 시 자동 시즌 전환) — 전체 제거
- 📍 웨이포인트 텔레포트 (`/wp tp`) — 제거. 저장·목록·삭제·공유는 유지
- 💰 가상 경제 (`/balance`, `/eco`) — 제거. 다이아몬드가 실질적 화폐(`/shop`, `/title buy`)라 별도 잔액 시스템은 뺌. 보상 수령(`/claim`)도 아이템 지급만 남음

**추가/변경됨**
- ⛏ 직업/스킬 시스템 신설 (광부·농부·전사·어부 + 힐/딜/포스 3종 스킬)
- 👥 팀 최대 인원 **3명** 제한
- ⚔️ 전투 중·킬스트릭 중 `/team tp`, `/team home` 차단
- 💤 수면 투표 **1일 1회** 제한 (통과된 날은 재투표 불가)
- 🕐 운영 스케줄 기본값 반전: `schedule.enabled: false`일 때 예전엔 "항상 열림"이었는데 이제 **"항상 닫힘(대기열)"**. OP는 항상 통과, 나머지는 관리자가 디스코드 `!opennow`로 열어야 함
- 🐳 도커 배포 체계 신설 — 운영/테스트 환경을 `docker-compose.yml` 하나로 분리 운영 (`-p` 프로젝트명으로 구분), 시크릿은 `.env`로 통합 관리
- 🏷️ 플러그인명/버전 `jeminSMPv1 1.0` → `JeminSMPv2 2.0`

## ⛏ 직업/스킬 시스템

### 직업 (택 1, 직업별 레벨/경험치는 따로 저장되어 전직해도 유지됨)
| 직업 | 퀘스트 (경험치 획득 행동) |
|---|---|
| ⛏ 광부 | 채굴의 여정 — 광물 채굴 (희귀할수록 진행도 ↑, 고대 잔해 최고) |
| 🌾 농부 | 수확의 여정 — 다 자란 작물 수확 (밀/당근/감자/비트/네더워트) |
| ⚔ 전사 | 전투의 여정 — 몹/플레이어 처치 (플레이어 킬이 더 높음) |
| 🎣 어부 | 낚시의 여정 — 낚시로 물고기 낚기 |

- `/job select <직업>` — 최초 선택은 즉시 적용, 전직은 같은 명령어 한 번 더 입력해야 확정
- `/job buyscroll` — 💎 15개로 **전직의 서** 구매, 우클릭하면 확인 절차 없이 바로 직업 선택 GUI(채팅 버튼)가 뜸

### 스킬 (힐/딜/포스/이동기 역할은 공통, 효과는 직업마다 완전히 다름 — 레벨 1~5)
| 직업 | ✚ 힐 | ⚔ 딜 | ☠ 포스 | 🏃 이동기 |
|---|---|---|---|---|
| ⛏ 광부 | 대지의 축복 — 회복+채굴속도 버프 | 낙석 — 광역 피해+둔화 | 지진 — 광역 넉업+강한 슬로우+시야 뿌옇게(진탕) | 굴착 돌진 — 바라보는 방향으로 3x3 단면 터널을 뚫으며 돌진 |
| 🌾 농부 | 수확의 축복 — 팀원까지 광역 회복 | 가시덩굴 — 광역 중독 | 뿌리 속박 — 강한 둔화+약화 | 새싹 도약 — 크게 도약 + 자신/팀원 속도 증가 |
| ⚔ 전사 | 전투 의지 — 자힐+저항 버프 | 돌격 — 전방 돌진하며 이동 경로의 적 전부 피해+넉백 | 포효 — 넓은 범위 약화 | 질풍 도약 — 높이 뛰어올라 착지 시 광역 충격파+넉백 |
| 🎣 어부 | 만조 — 재생(지속 회복) | 작살 — 단일 대상 피해+끌어당김 | 파도 — 광역 강한 넉백 | 갈고리 사출 — 바라보는 벽/블록에 걸려 그쪽으로 끌려감 |

- **레벨업은 전부 자동 해금** — 직업 레벨 1~15에서 딜→힐→포스 순서로 1레벨씩 순환 해금/성장(레벨 15에 셋 다 5레벨 완성), 16~20에서 이동기가 이어서 5레벨까지 성장. 플레이어가 직접 투자하는 스킬포인트는 없음.
- 레벨업에 필요한 경험치는 레벨이 오를수록 점점 가파르게 증가(제곱 곡선)
- 스킬 레벨 1→5로 갈수록 수치/지속시간 증가, 쿨다운은 60→50→40→30→20초로 단축
- 쿨다운 중엔 엔더펄/황금사과처럼 스킬템 아이콘에 회색 사선이 뜨고, 그래도 좌클릭하면 남은 시간을 채팅으로 알려줌
- **발동 방식**: 명령어가 아니라 **스킬마다 별도의 스킬템(종이 기반 아이템)** 으로 처리. 해금될 때마다 자동 지급되며, 핫바에서 원하는 스킬템을 골라 들고 좌클릭 또는 우클릭하면 발동(마인크래프트 기본 아이템 전환 그대로). 전직하면 새 직업에서 잠긴 스킬템은 회수되고 새로 풀린 건 지급됨. 사망 시 드롭되지 않고 부활하면 자동으로 다시 지급됨.
- `/skill use <heal|deal|force|move>` 명령어로도 직접 발동 가능(스킬템 없이 사용 가능)
- **관리자(OP)**: `/job admin give <닉네임> <경험치>` — 경험치 즉시 지급 / `/job admin setlevel <닉네임> <레벨>` — 레벨(퀘스트) 즉시 설정

### 리소스팩 (선택)
`resourcepack/` 폴더에 커스텀 아이템 모델 뼈대가 있음: 전직의 서 + 스킬템(직업×스킬 조합마다 다른 아이콘, 16개) 전부 종이(PAPER) 베이스에 CustomModelData 문자열 컴포넌트로 구분. 텍스처만 교체하면 실제 아이콘이 바뀜. 자세한 내용은 `resourcepack/README.md` 참고.

## 🕐 서버 운영 스케줄 & 대기열

### 동작 방식
1. `config.yml` 또는 디스코드에서 운영 슬롯 설정
2. 닫힌 시간에 접속하면 **공허 대기 월드**로 이동 (아무것도 없는 허공)
3. 대기 중: 인벤토리 보관, 관전 모드, 1분마다 오픈 시간 + 대기열 순서 표시
4. 서버 오픈 시: **대기열 순서대로** 2초 간격으로 원래 위치에 복귀

### 대기열 중 차단
- 다른 월드로 텔레포트 불가
- 모든 인게임 명령어 차단 (`/w`, `/msg` 채팅 제외)
- 낙하 피해 없음 / 허기 변화 없음

### 인게임 명령어
```
/schedule                  — 스케줄 현황 조회
/schedule on|off           — 활성/비활성 (OP)
/schedule add <요일> <시작>-<끝>
/schedule remove <번호>
```
